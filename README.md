# Państwa Miasta

Gra słowna online (wiele telefonów, kod lub link do dołączenia) i offline (jeden telefon). Instalowalna aplikacja webowa (PWA).

- Synchronizacja online przez publiczny broker MQTT po WebSocket (bez własnego serwera). Stan gry trzyma telefon gospodarza.
- Słowniki do automatycznego sprawdzania: `dict.js`. Odpowiedzi spoza słownika rozstrzygają gracze głosowaniem, ostatnie słowo ma gospodarz.
